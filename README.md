# Camilla Stewart — Freelance Data Entry Portfolio

A responsive, static portfolio website inspired by the supplied lavender-and-purple reference.

## Included
- Responsive navigation and hero section
- Services overview
- Four custom SVG project showcase images (illustrative sample data)
- About, testimonial, and contact sections
- Contact form that opens the visitor's email application

## Before publishing
1. Open `script.js` and replace `REPLACE-WITH-YOUR-EMAIL@example.com` with the email address where you want inquiries sent.
2. Replace the illustrative testimonial in `index.html` with a real, approved client testimonial or remove that section.
3. Update the project descriptions/images if you want to show actual completed client work. Current visuals are sample demonstrations, not claims of paid client work.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Wait for the Pages deployment to complete. The site URL will appear in **Settings → Pages**.

This is a plain HTML/CSS/JavaScript site; no build step is required.
